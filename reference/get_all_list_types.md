# Get all list types

Get all list types

## Usage

``` r
get_all_list_types(
  API_key = NULL,
  Server = chemical_api_server,
  verbose = FALSE
)
```

## Arguments

- API_key:

  The user-specific API key.

- Server:

  The root address for the API endpoint.

- verbose:

  A logical indicating if some "progress report" should be given.

## Value

A character list of types of lists.

## Examples

``` r
if (FALSE) {
get_all_list_types()
}
```
